A two-line warning to the writer's past self for the [make.fun bounty "Two Lines to Your Past Self"](https://make.fun/bounty/u-suga-two-lines-to-your-past-self-f36c83ca).

## What it does

`main.py` writes one short text to `/output/entry.txt`: line one warns the
writer's past self about one specific moment — brushing off a little
brother's request to teach him to ride his bike on the driveway one Saturday
in June — and line two says why it mattered, tracing what changed because
of that moment.

## Run

```sh
python3 main.py
```

Standard library only, Python 3.13. Deterministic: the same bytes every run.
No network, no randomness, no file reads outside this repository.
